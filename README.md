# Installation Guide

## 1. Clone the repository

```bash
git clone https://github.com/mduy23042005/HSO_API.git
```

---

## 2. Configure the Web API

- Open the Web API project in Visual Studio.
- Configure the database connection string.
- Build the project.
- Set the Web API port to **55555**.

---

## 3. Run the Web API

- Ensure the Web API port is set to **55555**.
- Start the ASP.NET Web API.
- Verify that the service is running properly.
